# Demo Script

## Project Name

**Smart Classroom Attendance System**

---

# Purpose

This demo script provides a step-by-step guide for demonstrating the Smart Classroom Attendance System. The demonstration highlights the main features of the MVP and shows how the system helps students and lecturers manage classroom attendance efficiently.

---

# Demo Overview

**Presenter:** Team Member

**Audience:** Lecturer, classmates, and evaluators

**Estimated Duration:** 5–7 minutes

---

# Demo Objectives

- Demonstrate student login using Student ID and Password.
- Show how students record attendance.
- Display attendance history.
- Demonstrate lecturer attendance management.
- Explain the benefits of the system.

---

# Demo Flow

## Step 1 – Introduction (30 Seconds)

### Presenter Says

> Good morning everyone. Today, we are presenting our project, the **Smart Classroom Attendance System**. Our system replaces manual attendance with a simple web-based solution where students log in using their Student ID and Password to record attendance, while lecturers can monitor attendance records digitally.

**Requirement Reference:** Project Overview

---
