# Feature Requirement Mapping

**Smart Classroom Attendance System**

This document maps the MVP features of the Smart Classroom Attendance System to the functional requirements and user stories defined in Lab 04. The mapping ensures that every feature supports user needs and project objectives.

| Student Login             | FR1            | US1           | Login Page              | Must Have   |

| Record Attendance         | FR5            | US2           | Attendance Confirmation | Must Have   |

### Must Have Features

* Student Login
* Lecturer Login

* Attendance Password Scanning
* Attendance Recording
* Attendance Confirmation

### Should Have Features

* Attendance History
* Search Attendance Records

### Could Have Features

* Course Management

## Conclusion

This mapping demonstrates that each feature of the Smart Classroom Attendance System is directly linked to a functional requirement and user story. The MVP focuses on essential attendance functions while allowing additional features to be implemented in future versions.
