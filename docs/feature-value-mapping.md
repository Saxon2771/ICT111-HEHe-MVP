# Feature-Value Mapping

**Smart Classroom Attendance System**

| Feature | User Value | Business Value | Requirement ID | User Story ID | Screen/Page | Priority |
|---------|------------|----------------|----------------|---------------|-------------|----------|
| Student Login (Student ID & Password) | Secure and personalized access | Prevent unauthorized access | FR1 | US1 | Login Page | Must Have |
| Lecturer Login | Secure access to attendance management | Protect lecturer data | FR2 | US5 | Login Page | Must Have |
| Student Attendance Check-in | Students can mark attendance quickly using Student ID | Reduces manual attendance time | FR3 | US2 | Student Dashboard | Must Have |

## Value Summary

The Smart Classroom Attendance System focuses on providing a secure and efficient attendance process using **Student ID and Password authentication**. Students can log in and record their attendance quickly, while lecturers can monitor attendance records, generate reports, and manage student attendance through a centralized dashboard. This approach reduces paperwork, minimizes attendance errors, and improves overall classroom efficiency.
