# Digital Go-to-Market Plan

## Project

**Smart Classroom Attendance System**

## Lab

**Lab 12 – Landing Page and Digital Go-to-Market**

---

## 1. Purpose of the Go-to-Market Plan

This plan explains how the Smart Classroom Attendance System can reach its early target users and encourage them to test the prototype.

The main goal is to create awareness, attract relevant users, encourage prototype testing, and collect useful feedback.

---

## 2. Product Overview

The Smart Classroom Attendance System is a web-based prototype that helps students, lecturers, and administrators manage classroom attendance.

The system allows users to:

- Log in using ID and Password
- Submit attendance
- View attendance history
- Search and filter records
- Monitor attendance metrics
- Manage attendance status

---

## 3. Main User Problem

Traditional attendance methods can take too much class time and may create inaccurate, duplicated, or missing records.

Students may also find it difficult to check their attendance history, while lecturers and administrators may not have a clear overview of classroom attendance.

---

## 4. Product Solution

The Smart Classroom Attendance System provides a simple browser-based solution for recording, viewing, and managing attendance.

It gives each user role a suitable dashboard:

- Students can submit and review attendance.
- Lecturers can monitor classroom records.
- Administrators can manage records and review system metrics.

---

## 5. Value Proposition

The Smart Classroom Attendance System helps schools reduce manual attendance work, improve record visibility, and manage classroom attendance more efficiently.

---

## 6. Target Early Users

### Primary Target Users

- University students
- College students
- Lecturers
- Course instructors

### Secondary Target Users

- Department administrators
- Academic coordinators
- IT support staff
- Student service teams

---

## 7. Early User Characteristics

The early users are people who:

- Regularly attend or manage classroom sessions
- Use smartphones or computers
- Experience problems with manual attendance
- Need faster access to attendance information
- Are willing to test a new academic prototype
- Can provide useful feedback
