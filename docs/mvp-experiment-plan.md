# MVP Experiment Plan

## Project Name

**Smart Classroom Attendance System**

---

# Purpose

The purpose of this MVP (Minimum Viable Product) experiment is to validate whether students and lecturers can successfully use the Smart Classroom Attendance System. The experiment focuses on the core features of the system, including user login, attendance recording, and attendance monitoring.

---

# Experiment Objective

The objectives of this experiment are to:

- Validate that students can log in using their Student ID and Password.
- Determine whether students can record attendance without assistance.
- Evaluate whether lecturers can easily monitor attendance records.
- Measure the usability and efficiency of the system.
- Collect user feedback for future improvements.

---

# MVP Experiment Type

**Simple Web Prototype**

The MVP will be developed as a frontend web application using HTML, CSS, and JavaScript. Attendance records will be stored in the browser's Local Storage.

# Experiment Procedure

### Step 1
Introduce the purpose of the Smart Classroom Attendance System.

### Step 2
Provide participants with login credentials.

### Step 3
Ask participants to log in using their Student ID and Password.

### Step 4
Ask students to record their attendance.

### Step 5
Ask students to check their attendance history.

### Step 6
Ask lecturers to review attendance records.

### Step 7
Observe user behavior without providing assistance unless necessary.

### Step 8
Collect feedback using the prepared feedback form.

---

# Data to be Collected

The experiment will collect:

- Login success rate
- Attendance submission success rate
- Time required to complete attendance
- Number of user errors
- User satisfaction score
- Suggestions for improvement

---

| Metric | Target |
|--------|--------|

# Risks

- Users may forget their passwords.
- Internet connection may be unstable.
- Users may be unfamiliar with the system.
- Browser compatibility issues may occur.

---

# Risk Mitigation

- Provide sample login accounts.
- Display clear validation messages.
- Test the system on multiple browsers.
- Observe users during testing and record difficulties.

---

# Conclusion

The MVP Experiment Plan provides a structured approach for testing the Smart Classroom Attendance System before full implementation. The experiment will validate the system's usability, functionality, and effectiveness while collecting valuable feedback from students and lecturers for future improvements.
