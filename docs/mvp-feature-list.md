# MVP Feature List

## Project
**Smart Classroom Attendance System**

## MVP Goal
Develop a simple web-based attendance system that enables students to record attendance using QR codes while allowing lecturers to monitor attendance records efficiently.

## Feature Prioritization (MoSCoW Method)

| Priority | Feature | Description | Reason |
|----------|---------|-------------|--------|
| **Must Have** | Student Login | Students log in using their university account. | Required to identify each student. |
| **Must Have** | Lecturer Login | Lecturers securely access the system. | Required to manage attendance. |
| **Must Have** | QR Code Generation | Lecturer generates a unique QR code for each class session. | Core attendance feature. |
| **Must Have** | QR Code Attendance | Students scan the QR code to mark attendance. | Main system functionality. |
| **Must Have** | Attendance Database | Store attendance records securely. | Essential for record keeping. |
| **Must Have** | Lecturer Dashboard | View attendance records for each class. | Required to monitor attendance. |
| **Should Have** | Attendance History | Students can view their attendance records. | Helps students track attendance. |
| **Should Have** | Attendance Report Export | Export attendance as PDF or Excel. | Useful for academic reporting. |
| **Should Have** | Attendance Status | Show Present, Late, or Absent. | Improves attendance tracking. |
| **Could Have** | Email Notifications | Notify students of attendance confirmation. | Improves communication. |
| **Could Have** | Attendance Analytics | Display attendance statistics and trends. | Useful for lecturers. |
| **Could Have** | Mobile Responsive Design | Support smartphones and tablets. | Better user experience. |
| **Won't Have (Current MVP)** | Face Recognition Attendance | Biometric attendance verification. | Too complex for MVP. |
| **Won't Have (Current MVP)** | GPS Location Verification | Verify student location during attendance. | Future enhancement. |
| **Won't Have (Current MVP)** | AI Attendance Prediction | Predict attendance trends using AI. | Outside MVP scope. |

---

## MVP Scope

The first version of the Smart Classroom Attendance System will focus on the core attendance process:

1. User Login
2. QR Code Generation
3. QR Code Scanning
4. Automatic Attendance Recording
5. Attendance Dashboard
6. Attendance History
7. Attendance Report Export

---

## Future Enhancements

Future versions of the system may include:

- Face Recognition Attendance
- GPS-based Attendance Verification
- Push Notifications
- AI-powered Attendance Analytics
- Mobile Application
- Integration with University Student Information System (SIS)

---

## MVP Success Criteria

The MVP will be considered successful if:

- Students can record attendance within **5 seconds** using QR codes.
- Lecturers can generate attendance QR codes instantly.
- Attendance records are stored accurately.
- Attendance reports can be viewed and exported.
- The system reduces classroom attendance time compared to manual attendance.
