# Privacy and Data Protection

## Data Collected
- Student ID
- Password
- Attendance records

## Purpose of Data Collection
- Authenticate users
- Record attendance
- Allow lecturers to monitor attendance

## Data Minimization
- Only necessary data is collected
- No sensitive personal data is stored

## User Awareness
- Users will be informed that:
  - Their ID is used for login
  - Attendance data is stored for academic purposes

## Data Protection Measures
- No real sensitive data used (prototype uses sample/demo data)
- Limited access:
  - Students: only their own attendance
  - Admin: full access

## Conclusion
The system minimizes data collection and protects user privacy at a basic level.
