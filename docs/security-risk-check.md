# Security Risk Check

## Identified Risks

### 1. Weak Passwords
- Risk: Users choose simple passwords
- Mitigation: Add password rules (minimum length)

### 2. Unauthorized Access
- Risk: Someone logs in using another student's ID
- Mitigation: Use password authentication

### 3. Admin Access Exposure
- Risk: Anyone accessing admin functions
- Mitigation: Restrict admin login

### 4. Data Exposure
- Risk: Attendance records visible publicly
- Mitigation: Limit access by role

### 5. Form Input Issues
- Risk: Invalid or empty inputs
- Mitigation: Add validation messages

## Conclusion
Basic security risks are identified and mitigated at MVP level.
