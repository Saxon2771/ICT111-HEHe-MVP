# Success Metrics

## Project Name

**Smart Classroom Attendance System**

---

# Purpose

This document defines the measurable success criteria used to evaluate the Minimum Viable Product (MVP) of the Smart Classroom Attendance System. These metrics will help determine whether the system meets user needs and project objectives during usability testing.

---

# Experiment Objective

Evaluate whether students and lecturers can use the Smart Classroom Attendance System effectively to record and manage attendance using Student ID and Password authentication.

---

# Success Metrics

| Metric | Description | Target |
|--------|-------------|--------|
| Login Success Rate | Percentage of users who successfully log in on the first attempt. | ≥ 90% |
| Attendance Recording Success Rate | Percentage of users who successfully record attendance. | ≥ 95% |
| Average Login Time | Average time required to log in. | Less than 30 seconds |
| Average Attendance Recording Time | Average time required to record attendance after login. | Less than 1 minute |
| Task Completion Rate | Percentage of users who complete all required tasks without assistance. | ≥ 90% |
| User Satisfaction Score | Average satisfaction rating from users (1–5 scale). | ≥ 4.0 |
| Error Rate | Percentage of users encountering system errors. | Less than 10% |
| Attendance Accuracy | Percentage of attendance records stored correctly. | 100% |

---

# Testing Tasks

Participants will complete the following tasks:

1. Open the Smart Classroom Attendance System.
2. Log in using Student ID and Password.
3. Record attendance.
4. View attendance history.
5. Log out.

---

# Evaluation Criteria

| Evaluation Area | Success Indicator |
|-----------------|------------------|
| Login Process | User logs in successfully without assistance. |
| Navigation | User easily navigates between system pages. |
| Attendance Recording | Attendance is recorded successfully. |
| Attendance History | User can view attendance records correctly. |
| Overall Experience | User reports the system is easy to use. |

---

# Data Collection Method

The following information will be collected during usability testing:

- Login success or failure
- Time required to complete each task
- Number of user errors
- Attendance recording accuracy
- User satisfaction rating
- User comments and suggestions

---

# Success Criteria

The MVP will be considered successful if:

- At least **90%** of participants log in successfully.
- At least **95%** of participants record attendance successfully.
- The average attendance recording time is less than **1 minute**.
- The average user satisfaction score is **4 out of 5** or higher.
- The system records attendance accurately without data loss.
- Lecturers can successfully view attendance records.

---

# Expected Outcome

The experiment should demonstrate that the Smart Classroom Attendance System is easy to use, reliable, and capable of replacing manual attendance methods. Positive results will support further development and implementation of the system.

---

# Conclusion

The success metrics provide measurable indicators for evaluating the Smart Classroom Attendance System MVP. These metrics ensure that the project is assessed objectively based on usability, efficiency, accuracy, and user satisfaction before moving to the next development stage.
