# User Testing Plan

## Project Name

**Smart Classroom Attendance System**

---

# Purpose

The purpose of this user testing plan is to evaluate the usability, functionality, and effectiveness of the Smart Classroom Attendance System. The testing will determine whether students and lecturers can successfully complete essential tasks and identify areas for improvement before the final release.

---

# Testing Objectives

The user testing aims to:

- Evaluate the login process using Student ID and Password.
- Verify that students can record attendance successfully.
- Assess whether users can navigate the system without assistance.
- Evaluate the lecturer dashboard for monitoring attendance.
- Collect feedback on usability and user satisfaction.

# Test Scenarios

## Scenario 1 – Student Login

**Objective**

Verify that students can successfully log in using their Student ID and Password.

**Steps**

1. Open the Smart Classroom Attendance System.
2. Enter Student ID.
3. Enter Password.
4. Click **Login**.

**Expected Result**

- Login is successful.
- Student dashboard is displayed.

**Requirement Reference**

- FR1
- US1

## Scenario 2 – Record Attendance

# Risks During Testing

- Users may forget their passwords.
- Browser compatibility issues may occur.
- Slow internet connection may affect testing.
- Participants may require assistance during first-time use.

---

# Risk Mitigation

- Provide test accounts for participants.
- Test the system on multiple browsers.
- Ensure a stable internet connection.
- Observe users without influencing their actions unless necessary.

---

# Expected Outcomes

At the end of user testing, the team expects to:

- Validate the usability of the Smart Classroom Attendance System.
- Confirm that users can complete core tasks independently.
- Identify any usability issues or technical problems.
- Collect feedback for improving the prototype.
- Prepare the system for the final presentation and project submission.
