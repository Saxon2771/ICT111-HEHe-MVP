# Observed Issues

| Issue | Severity | Recommendation |
|-------|----------|----------------|
| Users entered incorrect passwords during first login. | Low | Add password visibility toggle and clearer validation messages. |
| Attendance button was not immediately noticeable. | Medium | Increase button size and improve placement. |
| No password recovery feature. | Medium | Add a password reset function in a future version. |
| No attendance confirmation email or notification. | Low | Implement notifications in a future release. |

---

# User Suggestions

Participants suggested the following improvements:

- Add a password reset feature.
- Improve the design of the attendance button.
- Add email or in-app notifications after attendance is recorded.
- Provide a mobile-friendly interface.
- Allow students to edit their profiles.
- Add attendance statistics for students.
- Export attendance reports to PDF or Excel.
- Integrate the system with the university student portal.

# Conclusion

The user testing results indicate that the **Smart Classroom Attendance System** successfully met the project's objectives. All participants completed the main tasks without major difficulties, and the system achieved a **100% task completion rate** with an average user satisfaction score of **4.8 out of 5**. Feedback from students, lecturers, and the administrator highlighted that the system is easy to use and significantly improves the classroom attendance process compared to traditional paper-based methods.

Several enhancement opportunities were identified, including adding a password reset feature, improving the visibility of the attendance button, implementing notifications, and developing a mobile-responsive interface. These improvements will be considered in future versions of the system before full deployment.

---

# Recommendation

Based on the user testing results, the team recommends proceeding with the Smart Classroom Attendance System for the final project demonstration while implementing the identified improvements in future development phases.
