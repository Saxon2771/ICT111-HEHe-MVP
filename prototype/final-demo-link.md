## Local Demo Instructions

1. Download or clone the repository.
2. Open the repository folder.
3. Open `Landing page/index.html` in a browser.
4. Select the login or Get Started button.
5. If the landing-page button does not point to the prototype folder, open `prototype/login.html` directly.
6. Use one of the sample accounts below.

## Demo Data and Limitations

- This is an academic prototype.
- Demonstration data is stored in Browser Local Storage.
- Data is not synchronized across devices.
- Clearing browser storage removes the demonstration records.
- Do not enter real or sensitive student information.
- Report export and complete administrator student/course management must be completed before the final Lab 14 release.
